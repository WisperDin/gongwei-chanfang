# 工位禅房

上班摸鱼解压小游戏，单文件、无依赖、无构建。

在线玩：https://wisperdin.github.io/gongwei-chanfang/

| 场景 | 玩法 |
|---|---|
| 敲木鱼 | 点一下敲一下，敲的位置不同音高不同，每 108 响一次圆满 |
| 盘佛珠 | 拖着转、滚轮或空格拨一颗，盘得越多包浆越亮 |
| 挤牛奶 | 按住奶头往下拉，四个轮着挤，1000 ml 满一桶 |
| 抓猫狗 | 猫拎进猫舍、狗拎进狗舍，放对门才得分；键盘 ← 猫舍 / → 狗舍 |

快捷键：`1`–`4` 切场景，空格代替点击，`A` 自动挂机，`M` 声音，`Esc` / `B` 老板键。
